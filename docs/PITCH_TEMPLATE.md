# 3-Minute Pitch Template (8 slides, 20-25 seconds each)

Use the event colors: black background, orange (#ff8a00) and yellow (#ffd400) accents.

1. **Title** - Project name, tagline, team names. "Innovate | Build | Save Lives"
2. **Problem** - One real, local, specific problem (use 1-2 facts or numbers you can source). Who suffers and why current systems fail.
3. **Our solution** - One sentence + one screenshot. "We built ___ that helps ___ do ___ in ___."
4. **Live demo (60 seconds)** - The core flow only: user acts, AI/system responds, responder sees it on the map.
5. **How it works** - Architecture diagram: Citizen > API > AI/DB > Dashboard. Name the stack and the data sources.
6. **Impact** - Who benefits, how much time or how many lives or resources saved. One number.
7. **Feasibility and scale** - Runs on free/cheap tools, works with low internet, next steps: login/OTP, SMS alerts, integration with the district control room, Tamil voice input.
8. **Thank you** - Team, GitHub link, QR code to the live demo.

## One-sentence pitch formula
"For [user] who [problem], [product] is a [category] that [key benefit]. Unlike [current way], we [difference]."

## Q&A prepared answers
- *Is the data real?* Demo data is simulated; live weather and earthquake data are real public APIs (Open-Meteo, USGS).
- *What if there is no internet?* Reports can queue offline in a future version; AI falls back to rule-based triage.
- *What about false reports?* Next step: phone verification, duplicate detection by location and time, responder confirmation.
- *Privacy?* Collect minimum data, no accounts required, contact number optional.
- *How would it make money / sustain?* Free for NGOs and panchayats; pilot with a district office.
